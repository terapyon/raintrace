# Spec 10b 盛土の下の水路（暗渠）を仮定する Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 崩れたと仮定する候補が谷をまたぐ盛土なら、昔の谷底に沿って盛土の下を抜ける水路を自動で仮定し、崩れる前は水路で水が抜け、崩れた土が水路の端をふさぐと上流に水が溜まる様子を、崩れる前・後の再生で見比べられるようにする。あわせて 10 の「崩れる前と後を比べる」計算を取り除き、せき止めの数字を控えめにする。

**Architecture:** 水路の判定・溝の掘り込み・ふさがりの判定は純粋な関数として `src/simulation/debris/culvert.ts` に置き、Worker の `computeCollapse`（`src/workers/collapse.ts`）の中で、選んだ候補だけ判定する。水路を仮定したら、結果（`CollapsePayload`）に「溝ありの崩れる前の地形」と水路の線を足し、`CollapseSession` が「崩れる前」の表示にその地形を使う。閉じる・候補を変えると読み込んだ地形（溝なし）に戻す。

**Tech Stack:** TypeScript 6、React 19 + MUI 9、MapLibre GL 6.6、zustand 5、Vitest 4、Playwright 1.62。新しい依存は足さない。

**Spec:** `docs/superpowers/specs/2026-10-19-10b-culvert-design.md`（以下「spec」）。10 の spec `docs/superpowers/specs/2026-10-18-10-fill-collapse-design.md` と、その実装（ブランチ `feat/10-fill-collapse` 6613282）の上に積む。ブランチ `feat/10b-culvert`（7485b69）。

## Review Focus

1. **水路ありの「崩れる前」（溝あり）を表示中に、閉じる・候補や割合を変える・地点を選ぶ・Worker が異常終了する** → 読み込んだ地形（溝なし）に戻り、水路の線も消える（Task 5 のテスト）
2. **崩れた土が水路の端に届かない（ふさがらない）** → 崩れた後の地形にも溝があり、線は「通っている」の見え方で、パネルに「ふさがりました」を出さない（Task 2・Task 6・Task 7 のテスト）
3. **昔の地形が欠けている（NaN）セルが谷をふさぐ** → 水路はそこを通らない。他に道が無ければ水路を仮定しない（Task 1 のテスト）
4. **出口が無い・遠い（範囲の中に pit より低いセルが無い、道が 1,000 m を超える）** → 水路を仮定せず、10 と同じ見え方（Task 1 のテスト）
5. **割合・流れやすさを変えて計算し直す** → 前の結果の水路の線・`data-collapse-culvert` が残らない（Task 5・Task 6 のテスト）

```ts
export interface CulvertInput {
  /** 今の地形 */
  elevation: Float32Array
  /** 昔の地形（offsetM を足した高さ）。NaN は通れない */
  past: Float32Array
  validMask: Uint8Array
  /** 候補のセル（崩れる厚さ > 0 のセル）= 1 */
  candidate: Uint8Array
  /** 今の地形の窪地の解析 */
  labels: Int32Array
  depressions: readonly Depression[]
  size: number
  cellSizeM: number
  /** 長さの上限（m）。省くと CULVERT_MAX_LENGTH_M */
  maxLengthM?: number
}
export interface Culvert {
  /** pit から出口までのセル（4 近傍でつながる） */
  path: Int32Array
  /** 各セルの溝の底の高さ。pit から出口へ増えない */
  bed: Float32Array
  /** 候補の外の水路のセルのうち、候補のセルから水路に沿って CULVERT_END_CELLS 以内（入口側と出口側） */
  ends: Int32Array
  lengthM: number
  /** 上流の窪地の id（今の地形の解析） */
  depressionId: number
}
export function findCulvert(input: CulvertInput): Culvert | null
/** z の水路のセルを min(z, bed) にした写し */
export function carveCulvert(z: Float32Array, culvert: Culvert): Float32Array
/** ends のどこかに deposit ≥ CULVERT_BLOCK_DEPOSIT_M があれば true */
export function culvertBlocked(culvert: Culvert, deposit: Float32Array): boolean
```

- `findCulvert` の手順（spec 2）:
  1. 上流の窪地: `significant` な窪地のうち、セルが候補のセルであるか、候補のセルに 4 近傍で接するもの。複数なら `capacityM3` の大きいもの。無ければ null
  2. 出口: 窪地の外かつ候補の外の有効なセルで、`elevation < elevation[pit]`
  3. pit から出口への最も安い 4 近傍の道（ダイクストラ）。1 歩の費用 `cellSizeM × (1 + CULVERT_CLIMB_WEIGHT × max(0, past[j] − elevation[pit]))`。無効なセル・`past` が NaN のセルへは進まない。手数 × cellSizeM が上限（`maxLengthM`）を超えるセルへは広げない
  4. 道が無い、長さ `(path.length − 1) × cellSizeM` が上限を超える、道に候補のセルが無い、のどれかなら null
  5. `bed[k] = min(elevation[path[k]], past[path[k]])` を pit から順に `bed[k] = min(bed[k], bed[k−1])` で増えないようにする
- 新しいテスト用の地形 `valleyWithCrossFill(): { grid: DebrisGrid; removed: Float32Array; past: Float32Array }` を `testTerrain.test-support.ts` に足す: 10 の V 字谷（`valley(r, c)`）をまたいで、行 24〜29・列 18〜42 に、天端が `valley(24, VALLEY_COL) + 6` の平らな盛土（`elevation = max(valley, 天端)`、`removed = elevation − valley`）。`past` は谷そのもの（盛土なし）
