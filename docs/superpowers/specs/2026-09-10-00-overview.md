- Status: 裁定済み（2026-09-10）
- 日付: 2026-09-10
- 入力: `specs/base-spec.md`（何を作るか）、`specs/tech-spec.md`（何で・どう作るか）

---

## 1. 本書の位置づけ

base-spec と tech-spec を、実装計画（implementation plan）を1本ずつ立てられる大きさに分けた spec 群の索引である。各 spec の範囲、依存関係、PoC 完成条件との対応、そして**ユーザーの最終裁定が必要な論点の一覧**（§6）をまとめる。

## 2. 進め方

1. ブランチ `spec/implementation-specs` で、本書を含む全 spec を作成する
2. レビュー役がレビューし、指摘を反映する
3. ユーザーが §6 の論点を最終裁定し、結果を各 spec と tech-spec に反映する（tech-spec の改訂は §7）
4. `main` へマージする
5. spec ごとにブランチを切り、implementation plan を立てて実装する

S（スパイク）と 05 は、スパイクの結論が出た時点で 05 を改訂し、再レビューを経てから実装する（R05-3）。
