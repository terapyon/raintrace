# A の流れの矢印（symbol レイヤー、spec 05 §3.3）

シート: `sheets/a-arrows.jpg`（合成の場面、固定の水、ズーム 17）

| 問い | 観察 | 根拠のコマ |
|---|---|---|
| (a) 矢印は地形の面に載り、垂直強調（1・5・10）に従って高さが変わるか | 載る。20m おきの矢印の格子は 1 行目（above/map）の ×1・×5・×10 で一貫して地形の起伏（すり鉢のへこみ・平らな台地）に追従して見え、格子の間隔・位置が三段とも自然に対応している。これは `showArrows` 側で高さを一切計算していない（`arrowFeatures` は lon/lat だけを渡す）ため、MapLibre 自身が地形（`spike-dem` ソース）に基づいて symbol を自動で地表に載せている挙動 | 1 行目の 6 コマ（above/map ×1・×5・×10、pitch 0・60） |
| (b) 水面の Custom Layer の後（above）・前（below）に置いたとき、池（水深 2m）と膜（1cm）の上で水面に隠れるか、水面の上に描かれるか | **描画順（above/below）だけで occlusion が決まる。pitch0（真上）のコマで明瞭**: ×1 p0・×10 p0 のどちらも、above では 1cm の膜の上にも、水深 2m（×10 では見た目の高さ 20m）の池の上にも矢印が白く鮮明に描かれる。below では膜・池のどちらも矢印が完全に隠れる（一様な青のまま）。**水深に関係なく、above に置いた symbol は常に水面の上に描かれる**——MapLibre の symbol レイヤーは、水面の Custom Layer が書き込む GL の深度値とは無関係に、style のレイヤー順どおり 2D 的に上書き合成されていると考えられる。以前の記録（初版）で「池は above/below どちらでも隠れる」としたのは誤りで、pitch0 のコマを見落としていた（pitch60 のコマだけでは矢印が `icon-pitch-alignment: 'map'` により薄く潰れて見えづらく、判別を誤った）。pitch60 のコマは矢印が視線に対しほぼ水平に潰れて非常に薄くなるため、この (b) の結論は pitch0 のコマを根拠にする | 1 行目・2 行目の ×1 p0・×10 p0（above/map ×1 p0・below/map ×1 p0・above/map ×10 p0・below/map ×10 p0 の 4 コマ） |
| (c) 水面の高さへ上げる手段 | MapLibre 6.6.0 の style spec（@maplibre/maplibre-gl-style-spec 26.4.1）の symbol に `symbol-z-elevate` は無い。高さに効く設定は無く、`icon-pitch-alignment`（map・viewport・auto）は向き、`icon-translate`（paint）は画面か地図の平面での 2 次元のずれだけ。3 行目の viewport 揃えのコマで高さが変わらないことを確かめた: `above/viewport` は `above/map` と比べて矢印の見た目の形（"V" 字が細く潰れる vs. カメラに正対したふっくらした形）は変わるが、地面・池・膜との位置関係（隠れるか見えるか）は変わらない。すなわち `icon-pitch-alignment` は矢印の描画時の向き（ビルボードか地図に寝かせるか）だけを変え、アンカーの高さ（地形の標高）には影響しない | 3 行目（above/viewport ×1・×5・×10 p60）。特に膜の帯を高倍率で切り出すと、map 揃えは薄い "V"、viewport 揃えは太い三角に近い形になるが、どちらも同じ高さ（膜の中）に位置する |

**05 への申し立ての材料（`showArrows` の実装から。(b) の訂正を反映）**: symbol の高さは MapLibre の地形（terrain ソース）から自動で決まり、A・A' が使う水面の高さ（シミュレーションの標高、または A' の `queryTerrainElevation`）を明示的に反映する手段が無い。ただし (b) で確かめたとおり、above（水面の Custom Layer の後）に置けば、水深に関係なく矢印は常に水面の上に描かれる——occlusion の心配は無い。一方で、矢印の実際の 3D 位置は地形（地表）の高さのままで、水面の高さには合っていない。そのため、斜めの視点（pitch60・85）では、矢印の描かれる画面位置は「地表にある点」を投影した位置であり、「水面の高さにある点」を投影した位置（水面の高さ分だけ手前・上にずれる）とは一致しない——視差（パララックス）による位置のずれが生じるはずである（今回はこの位置ずれそのものは定量的に確かめていない。pitch60 のコマは矢印が薄く潰れて視認しにくく、位置のずれを目視で判別するのは難しかった）。05 で A 系の矢印を使うなら、above の symbol レイヤーで occlusion は回避できるが、見た目上「水面よりわずかに低い位置に矢印が浮いている」ように見える可能性がある点に注意し、必要なら Custom Layer（three.js 側）で水面の高さに矢印を明示的に描くことを検討する。
